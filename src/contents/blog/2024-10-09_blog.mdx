# 実装中です🚧

昨年に Gatsby.js のガワだけ用意して長らく放置していたのですが、再度 HP 公開、アプリ開発のモチベーションが湧いてきました。
開発当初は mui の Blog コンポーネントと Github pages でサクッと終わると期待していたものの、イザ実装を始めてみるとあら不思議。
mui の Blog は mdx を読み込むような仕組みはなく、mdx のパスとテキストだけ差し替えれば終わりやろーな期待が外れました。

結局フルスクラッチになってしまいましたが、技術的な内容を発信する意図もあったので、それで良かったのかもしれません。

一応 Gatsby.js に関しては、今も別途受託中の案件でサイトをひとつ運用しており、慣れています。
mdx の利用は初だったため、そこに1日要しました。
そのため実装しているプログラムに関しては、コピペの寄せ集めではありません。

Paiza の技術者検定では初使用の言語を使って S ランクを保有しており、開発者スキルは一般的なレベルよりは高いほうだと自負しておりますが、今や IT 技術者は日本だけでも 100 万人時代。
上位数% に該当するとしても、上にはまだ万単位のデキる方がウヨウヨしています。
そこに挑むにはもう年を取りすぎました。

立つ場所がなければ、座る場所を探せばいいじゃない。そんな感じです。

SNS で時間を取りたくもないので、基本的に一方的な発信と、アプリが完成したらサポート窓口の設置程度に利用するつもりです。
マイペースでのんびり開発ライフを楽しんでいく所存です。

さて、アプリ公開までがんばりますか。
